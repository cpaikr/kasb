# AGENTS

This repo is a Markdown-first guide for designing agent tools, not a tool implementation.

## Start Here

1. Read [README.md](README.md) for the repo stance and reading order.
2. Read [ARCHITECTURE.md](ARCHITECTURE.md) for document ownership.
3. Edit the relevant file in [docs/](docs/) instead of spreading the same rule across multiple files.

## Working Rules

- Keep each idea in one canonical document.
- Prefer links to existing guidance over repeating it.
- Keep changes small, explicit, and easy to scan.
- When adding new guidance, put it near the most relevant existing doc.
